# JavaScript Looping & Conditional Programs

A beginner-friendly JavaScript project that demonstrates the use of **for loops**, **if-else statements**, **logical operators**, and **number-based problems**.

---

# 📁 Project Structure

```
JavaScript-Looping-Programs/
│
├── index.html
├── Programs.js
└── README.md
```

---

# 🚀 How to Run

## Method 1: Using Browser

1. Create an **index.html** file.

```html
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Looping Programs</title>
</head>
<body>

<h2>Open Browser Console (F12)</h2>

<script src="Programs.js"></script>

</body>
</html>
```

2. Save both files in the same folder.
3. Open **index.html** in your browser.
4. Press **F12** → **Console**.
5. View the program output.

---

## Method 2: Using Node.js

Open the terminal and run:

```bash
node Programs.js
```
